Reference clips of each word being written with the correct posture, served at
/videos/...

Name each file after the word, lowercase: `welcome.mp4`, `to.mp4`, `the.mp4`,
`pen.mp4`, `pal.mp4`. When the struggle score stays high the app plays the clip
for the current word in a small panel beside the word; if no file is there, a
grown-up can pick a clip from the device instead.
